# 设计文档：ESP32-S3 交互小系统

> 版本：v0.1.0　|　日期：2026-11-19　|　状态：可编译（无硬件环境下按官方引脚定义，未烧录验证）

## 1. 项目概述

基于 ESP32-S3 的交互小系统：按键切换 SSD1306 OLED 显示内容，按键伴有声光反馈。
工程采用 ESP-IDF v5.2 + FreeRTOS + LVGL v9，重点考察任务划分、任务间通信与外设联调。

**完成范围**：必做项全部实现。选做项已完成 3 项（三色灯呼吸、测试用例清单、简版项目计划），其余（NTP 获取时间、NTP 失败降级、LVGL 多级菜单）未实现，见第 8 节说明。

## 2. 硬件接口

开发板：ESP32-S3-DevKitC-1。以下引脚依据 Espressif 官方原理图 / 数据手册定义，
**无硬件环境，烧录前请核对实际接线**。引脚集中在 `main/pinmap.h`，改板仅需改该文件。

| 信号 | GPIO | 方向 | 说明 |
|---|---|---|---|
| OLED SDA | GPIO8 | I/O | I2C 数据线（外接 4.7kΩ 上拉） |
| OLED SCL | GPIO9 | 输出 | I2C 时钟线（外接 4.7kΩ 上拉） |
| OLED 地址 | 0x3C | — | 7-bit 地址（部分模块为 0x3D） |
| 按键 BOOT | GPIO0 | 输入 | 板载按键，按下低电平，内部上拉 |
| LED | GPIO4 | 输出 | 高电平点亮，需串联限流电阻 |
| 蜂鸣器 | GPIO5 | 输出 | 主动式，高电平鸣响，建议三极管驱动 |
| RGB-R | GPIO6 | 输出 | 三色灯红通道（LEDC PWM，选做项，需串限流电阻） |
| RGB-G | GPIO7 | 输出 | 三色灯绿通道（LEDC PWM，选做项） |
| RGB-B | GPIO10 | 输出 | 三色灯蓝通道（LEDC PWM，选做项） |

## 3. 软件架构（分层）

```
┌─────────────────────────────────────────────┐
│  tasks/   input_task  ui_task  feedback_task rgb_task │  FreeRTOS 任务层
├─────────────────────────────────────────────┤
│  ui/      ui.c  ui_pages.c（LVGL 界面）       │  界面层
├─────────────────────────────────────────────┤
│  drivers/ i2c_bus ssd1306 button led buzzer  │  驱动层
│           lvgl_port（LVGL 移植）              │
├─────────────────────────────────────────────┤
│  硬件：SSD1306(I2C)  按键(GPIO)  LED 蜂鸣器    │
└─────────────────────────────────────────────┘
```

## 4. FreeRTOS 任务划分

| 任务 | 栈（字节） | 优先级 | 职责 |
|---|---|---|---|
| `input_task` | 4096 | 5 | 从队列读按键原始事件 → 软件消抖 → 长短按识别 → 发语义事件 + 触发反馈 |
| `ui_task` | 8192 | 5 | 消费按键事件切换页面；周期调用 `lv_timer_handler()` 驱动 LVGL |
| `feedback_task` | 2048 | 4 | 等待事件组触发位，产生 LED 闪 / 蜂鸣响 |
| `rgb_task` | 2048 | 3 | 三色灯呼吸：每 20ms 刷新 3 路 LEDC PWM（选做项，独立运行不参与 IPC） |

> 所有 LVGL API 只在 `ui_task` 单任务中调用（LVGL 非线程安全），
> 按键通过队列异步转交，避免在 ISR 或其它任务直接操作 LVGL。

## 5. 通信方式

| 机制 | 对象 | 生产者 → 消费者 | 用途 |
|---|---|---|---|
| 队列 | `g_button_queue` | ISR → `input_task` | 原始按键事件（`raw_btn_event_t`，含时间戳/电平） |
| 队列 | `g_ui_queue` | `input_task` → `ui_task` | 语义化事件（短按/长按） |
| 事件组 | `g_feedback_eg` | `input_task` → `feedback_task` | 反馈触发位（`FEEDBACK_BIT_LED` / `FEEDBACK_BIT_BEEP`） |
| 互斥量 | `i2c_bus` 内部 | — | 保护共享 I2C 总线（当前单设备，预留） |

> `rgb_task`（呼吸灯，选做项）不参与任务间通信，独立按周期运行、无共享状态。

**ISR 安全**：按键中断只调用 `xQueueSendFromISR` 与 `esp_timer_get_time()`（两者均 ISR 安全），
绝不在 ISR 中延时、打印或做消抖（消抖在 `input_task` 完成）。

## 6. 关键设计点

1. **单色屏 + LVGL 集成**（最易翻车点）：
   - 运行时通过 `lv_display_set_color_format(LV_COLOR_FORMAT_L8)` 使用 8bit 灰度格式，
     全屏缓冲仅 128×64×1 = 8KB，避免 16bit 色深浪费内存；
   - `flush` 回调按阈值 127 二值化，将 L8 打包为 SSD1306 的 1bpp GDDRAM
     （每字节 8 像素，bit0 = 页内最顶行）；
   - 使用深色主题（背景黑、文字白），保证单色屏显示不反相。
2. **按键消抖与长短按**：边沿消抖（距上次有效边沿 <20ms 的边沿丢弃，同时过滤按下/释放抖动，
   保证声光反馈只触发一次），长按阈值 1000ms，状态机在 `input_task`。
   时间戳改用 `esp_timer_get_time()` 64 位微秒，避免 32 位毫秒约 49.7 天回绕（已修复 Issue #1）。
3. **LVGL tick 源**：`esp_timer` 每 2ms 调 `lv_tick_inc(2)`，`ui_task` 按 `lv_timer_handler()`
   返回的空闲时间休眠，避免忙等。

## 7. 构建与验证

```bash
idf.py set-target esp32s3
idf.py build
```

验收标准（远程）：编译通过。烧录验证需在真实硬件上补做，重点核对：
- SSD1306 地址（0x3C/0x3D）与显示方向（若方向颠倒，调整 `ssd1306.c` 初始化序列中的 `0xA1`/`0xC8`）。
- BOOT 键按下电平极性。

## 8. 未实现功能与后续思路（选做项）

| 选做项 | 状态 | 说明 |
|---|---|---|
| 三色灯呼吸 |  已实现 | 3 路 LEDC PWM（`drivers/rgb_led.c`）+ 独立任务 `rgb_task`，三路正弦波相位差 120° 叠加呼吸渐变 |
| 测试用例清单 |  已实现 | `docs/test-cases.md`，覆盖编译、消抖、长短按边界、页面切换、反馈时序、呼吸灯 |

| NTP 获取时间 | 未实现 | 需启用 WiFi + 联网，与本工程“离线精简组件”策略冲突；后续新增 `ntp_task` 用 `esp_netif_sntp` 取时 + `setenv("TZ")` 设时区 |
| NTP 失败降级 | 未实现 | 依赖 NTP；思路：失败降级为本地占位时间并定时重试，结果经队列交 `ui_task` |
| LVGL 多级菜单 | 未实现 | 在 `ui_pages.c` 基础上引入“菜单栈”，长按进入、短按选择/返回 |

剩余未实现项（NTP 相关、多级菜单）如要启用，建议先做 NTP + 降级（性价比高），对应“桩函数占位 + 文档说明”即可满足验收。
