# 测试用例清单（选做项）

> 目的：为“按键切换 + 声光反馈 + 三色灯呼吸”提供可执行的验收与回归清单。
> 远程阶段只验收编译（TC-01）；其余用例需在真实硬件上执行，供烧录后回归。

## 环境与前置

- 开发板：ESP32-S3-DevKitC-1；显示：SSD1306 128×64（I2C，地址 0x3C）
- 外接：单色 LED（GPIO4）、有源蜂鸣器（GPIO5）、共阴极 RGB（GPIO6/7/10，各串限流电阻）
- 工具：`idf.py build`（编译）、`idf.py monitor`（观察串口日志）
