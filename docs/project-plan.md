## 关键路径与风险

1. 单色屏 + LVGL 集成是最大风险（已用 L8 灰度 + 阈值二值化解决，待实机验证显示方向）。
2. 按键抖动需边沿消抖，否则声光反馈会重复触发（已修复）。
3. NTP 依赖 WiFi 与联网，与本工程“离线精简组件”策略冲突，故后置。
